# YOLO Object Detection — From Scratch

A hands-on learning project to understand the complete YOLO object detection workflow.

## What this project demonstrates

- Custom dataset creation
- YOLO annotation format
- Dataset configuration using `data.yaml`
- YOLO model training
- Validation
- Object detection inference
- Confidence scores
- Bounding box visualization

## Dataset

A small synthetic dataset containing:

- Circle
- Square

The dataset was created specifically to understand the object detection pipeline before moving to real-world datasets.
